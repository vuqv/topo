# Nascent-chain ↔ ribosome nonbonded interaction — TOPO vs O'Brien

**Scope (translation only).** This compares *only* the **inter** nonbonded interaction between
**nascent-chain beads and ribosome beads** during continuous synthesis — the excluded volume
that sets the ribosome's effective shape and gates how the nascent chain threads and exits the
tunnel. The **intra**-nascent-chain nonbonded is structure-based (the native 12-10-6 Gō contact
map + non-native excluded volume from `build_nonbonded_interaction`) and is **out of scope here**.
All values in OpenMM units (nm, kJ/mol). Both confirmed **from code** (not docs).

> **Headline:** topo's NC↔ribosome excluded volume is **~1000–3000× weaker** than O'Brien's at
> typical clash separations, from **two compounding causes**: (1) topo uses a **pure `ε(σ/r)¹²`**
> wall vs O'Brien's **12-10-6** (leading repulsion `13·ε`), and (2) topo combines per-bead radii
> with an **average** rule `σ_ij=½(σ_i+σ_j)` while O'Brien **sums** them `R_ij=Rmin/2_i+Rmin/2_j`,
> so topo's contact distance is ~0.6× O'Brien's. This directly explains the nascent–ribosome
> penetration / clash / weak lateral confinement seen in the runs.

---

## 1. O'Brien (confirmed from code)

`continuous_synthesis_v6.py:create_elongation_system` builds the system from the **`rnc.xml`**
force field and uses **`custom_nb_force = system.getForce(4)`** for *all* nonbonded, restricting
it to nc×ribosome via interaction groups (`addInteractionGroup(nc_atom_index, AtR_atom_index)`
etc.). There is **no separate NC↔ribosome force and no σ override** — it is the same
`CustomNonbondedForce` generated by `parse_cg_prm.py`:

$$U_{ij}(r) = \underbrace{k_e\frac{q_iq_j}{\epsilon_r r}e^{-r/l_D}}_{\text{Debye–Hückel}}
+ \underbrace{a_{ij}/r^{12} + b_{ij}/r^{10} + c_{ij}/r^{6}}_{\text{12-10-6}}$$

with (parse_cg_prm.py lines 234-246)

$$a_{ij}=13\,\varepsilon_{ij}R_{ij}^{12},\quad b_{ij}=-18\,\varepsilon_{ij}R_{ij}^{10},
\quad c_{ij}=4\,\varepsilon_{ij}R_{ij}^{6}\;\Rightarrow\;
U^{126}_{ij}=\varepsilon_{ij}\!\left[13\big(\tfrac{R_{ij}}{r}\big)^{12}
-18\big(\tfrac{R_{ij}}{r}\big)^{10}+4\big(\tfrac{R_{ij}}{r}\big)^{6}\right]$$

| quantity | value (NC↔ribosome) | source |
|----------|---------------------|--------|
| ε_ij | √(ε_i·ε_j) = **0.000132 kcal/mol = 5.52×10⁻⁴ kJ/mol** (all beads share ε; no NBFIX between NC & ribosome) | `rnc.prm` NONBONDED |
| **R_ij (contact)** | **Rmin/2_i + Rmin/2_j** (SUM of the two per-bead Rmin/2) | `parse_cg_prm.py:240` `R_min=R_min1+R_min2` |
| Rmin/2 ribosome | **R 0.523, P 0.645, BR 0.534 nm** | `rnc.prm` (=Rmin/2 col, ÷10) |
| Rmin/2 nascent | per-residue, mean **0.385 nm** (range 0.224–0.544) | `rnc.prm` A-types |
| well depth | −ε_ij at r=R_ij (≈ −5.5×10⁻⁴ kJ/mol; negligible attraction) | 12-10-6 |
| cutoff / switch | **2.0 nm / 1.8 nm** | `continuous_synthesis_v6.py:1218-1219` |
| integration | `constraints=AllBonds` | `create_elongation_system` |

## 2. TOPO (confirmed from code)

`topo.csp.ribosome.append_ribosome` adds a **dedicated** NC↔ribosome force (separate from the
nascent contact/Yukawa forces), restricted to `{nascent}×{ribosome}`:

```python
nc = mm.CustomNonbondedForce("eps*(sigma/r)^12; sigma=0.5*(sigma1+sigma2)")
nc.addGlobalParameter("eps", RIBO_NC_EPS_KJ)        # 0.000132*4.184 = 5.52e-4 kJ/mol
for s in nascent_model.rf_sigma: nc.addParticle((s,))   # nascent per-bead sigma
for s in ribo.radii_nm:          nc.addParticle((s,))   # ribosome per-bead sigma
```

$$U^{\text{topo}}_{ij}(r)=\varepsilon\Big(\tfrac{\sigma_{ij}}{r}\Big)^{12},\qquad
\sigma_{ij}=\tfrac{1}{2}(\sigma_i+\sigma_j)\quad(\textbf{average})$$

| quantity | value (NC↔ribosome) | source |
|----------|---------------------|--------|
| ε | **5.52×10⁻⁴ kJ/mol** (`RIBO_NC_EPS_KJ`) — **matches O'Brien** | `ribosome.py:42` |
| form | **pure `ε(σ/r)¹²`** (no 10/6 terms, no attraction) | `ribosome.py:361` |
| **σ_ij (contact)** | **½(σ_i+σ_j)** (AVERAGE) | `ribosome.py:361` |
| σ nascent (`rf_sigma`) | `model_parameters['topo'][res]['radii']`, mean **0.588 nm** (0.45–0.678) | `setCARadiusPerResidueType` |
| σ ribosome (`radii_nm`) | from `load_obrien_ribosome` = **O'Brien Rmin/2** (R 0.523 …) | `ribosome.py:load_obrien_ribosome` |
| electrostatics | handled by the *separate* `yukawaForce` (same DH form) — not in this force | `system.py:addYukawaForces` |
| cutoff / switch | **2.0 nm / 1.8 nm** — matches O'Brien | `ribosome.py` |

## 3. Your "Rmin/2 = σ/2" question — CONFIRMED from code

O'Brien's tabulated value is **Rmin/2**, a *per-bead radius*; the pair contact distance is the
**sum** `R_ij = Rmin/2_i + Rmin/2_j`. topo's rule is the **average** `σ_ij = ½(σ_i+σ_j)`. The
average reproduces the sum **only if** each `σ_i = 2·(Rmin/2_i) = Rmin_i` (the full per-bead
*diameter*). In other words **Rmin/2 = σ/2**, exactly as you guessed — O'Brien's tabulated radius
is half of the "σ" that topo's average rule expects.

But topo feeds the **radius** (`Rmin/2`) straight in as `σ` (ribosome `radii_nm = Rmin/2`; nascent
`rf_sigma` are radius-scale values, mean 0.588 vs O'Brien Rmin/2 mean 0.385), **not** the doubled
diameter. So topo's average-of-radii is ~half of O'Brien's sum-of-radii:

- O'Brien `R_ij = Rmin/2_n + Rmin/2_R = 0.385 + 0.523 = ` **0.908 nm**
- topo `σ_ij = ½(0.588 + 0.523) = ` **0.555 nm**  → **0.61× O'Brien** (≈ the factor-2 you suspected,
  partly offset because topo's nascent radii are larger than O'Brien's Rmin/2).

## 4. Quantitative impact (representative pair: mean nascent × ribosome R bead)

Repulsion energy `U(r)` (kJ/mol), same ε in both:

| r (nm) | O'Brien 12-10-6 | topo `ε(σ/r)¹²` | ratio O'Brien/topo |
|--------|-----------------|-----------------|--------------------|
| 0.45 | 21.7 | 0.0069 | **3146×** |
| 0.50 | 5.44 | 0.0020 | **2787×** |
| 0.60 | 0.436 | 2.2×10⁻⁴ | 1993× |
| 0.70 | 0.0394 | 3.4×10⁻⁵ | 1144× |
| 0.80 | 2.3×10⁻³ | 6.9×10⁻⁶ | 327× |

Two multiplicative effects: **(a)** leading coefficient `13ε` (O'Brien) vs `ε` (topo) = **13×**;
**(b)** contact distance 0.908 vs 0.555 nm → `(0.908/0.555)¹² ≈ 460×` more repulsion at fixed r.
Combined ≈ 13×460 ≈ thousands× (the table's ratio varies with r). Net: **a nascent bead must come
~1000× closer (in energy terms) before topo pushes back** — so it slides into/through ribosome
beads that O'Brien's wall would firmly exclude. This is the mechanistic root of the residual
clash, the weak lateral confinement, and the reduced extrusion.

## 6. Recommendation (to make NC↔ribosome match O'Brien)

To reproduce O'Brien's tunnel excluded volume (and most likely resolve the clash without an ad-hoc
y-z wall), change the `append_ribosome` NC force to:

1. **12-10-6 form** (or at minimum the `13ε` leading coefficient + the −18/+4 tail), not pure `(σ/r)¹²`.
2. **Sum combination rule**: `R_ij = Rmin/2_i + Rmin/2_j` (equivalently keep `½(σ_i+σ_j)` but feed
   `σ = 2·Rmin/2` = the diameter — your "Rmin/2 = σ/2" point).
3. **Consistent Rmin/2 for the nascent beads** — use O'Brien's per-residue Rmin/2 (from the protein
   `.prm`) for the nascent `σ` rather than the current `model_parameters` radii, so both sides of
   the pair use the same convention.

ε and cutoffs already match, so these three changes fully align the NC↔ribosome excluded volume.
(Verified numerically above; energies/curves reproducible from `rnc.prm` + `model_parameters`.)
