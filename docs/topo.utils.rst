topo.utils.multichain module
----------------------------

Replicate a single chain into non-interacting copies, and the inverse —
:func:`~topo.utils.multichain.split_chains` — which splits a combined multi-copy
trajectory back into one DCD per copy (memory-bounded streaming; CLI
``python -m topo.utils.multichain``).
